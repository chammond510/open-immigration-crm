# Code of conduct

We want a professional, welcoming project where people can collaborate without harassment or intimidation.

Be respectful, specific, and constructive. Assume good faith while remaining rigorous about security and privacy. Do not publish personal, client, privileged, or confidential information. Harassment, discrimination, threats, sexualized conduct, deliberate humiliation, and sustained disruption are not acceptable.

Report conduct concerns privately through the repository owner's GitHub profile. Maintainers may edit or remove content and temporarily or permanently restrict participation when needed to protect the community.
