# Roadmap and product boundary

## Priorities

1. Accessibility and keyboard/screen-reader quality
2. Safer operations: backup verification, upgrade checks, and security documentation
3. Data portability and deliberate deletion/retention tools
4. Performance and usability for small-firm workloads
5. Narrow, provider-neutral extension points only when real maintainers and tests exist

## Non-goals for core

- AI assistants, summarization, drafting, or autonomous case actions
- Legal forms, filing strategies, case-type checklists, or intake-question templates
- Payment processing or accounting
- Gmail, Outlook, Google Drive, OneDrive, or calendar sync
- SMS, calling, or marketing automation
- E-signature and document-generation suites
- Multi-tenant SaaS administration

These can be separate projects if a community needs them. Core should remain understandable by a small firm and a small maintainer team.
