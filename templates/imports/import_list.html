How rows are matched

  • A row whose email or phone matches a contact already in the CRM, or one earlier in the file, does not add a contact or change the existing one. If the row has a matter, the matter is added to that contact; if not, the row is skipped.
  • A matter whose receipt number is already in the CRM, or earlier in the file, is skipped.
  • Rows are checked like the web pages' forms. A row that fails is skipped, with the reason, and you can download the skipped rows to fix and import again.
