How tokens work

Who they act as
The staff member who created them, with that person's access. Billing scopes also need billing access.
Expiry
Every token expires, after one year at most.
Storage
Only a fingerprint of each token is kept, so a lost token cannot be shown again. Revoke it and create another.
Limits
{{ hourly_limit }} requests an hour per token. Nothing can be deleted through the API.
